# JW Talks Planner

Telegram-бот на TypeScript (`Telegraf` + `PostgreSQL`) для планирования публичных речей.

## Возможности

- **Управление расписанием**: просмотр, добавление, редактирование и удаление речей.
- **Проверка истории по номеру речи**: `/check` → ввод номера речи → ответ, была ли такая речь и даты проведений.
- **Данные речи**: дата, песня, номер речи, название, докладчик, телефон.
- **Справочник речей**: `/plans` показывает список `номер -> название`; при `/add` название подставляется автоматически.
- **Несколько общин**: один пользователь может иметь доступ к одной или нескольким общинам.
- **Выдача доступа**: администратор использует `/grant @username [община]`; доступ применяется после `/start` пользователя.
- **Настройки собрания**: `/meeting_schedule` (день, время, переименование).
- **Уведомления**:
  - за 7 дней до речи — просьба подтвердить докладчика;
  - напоминание накануне, за 1 день до речи.
- **Статистика**: `/stats` показывает сводку, ТОП тем, постраничный полный список и даёт выгрузки XLSX (полный список + матрица по годам 2020-2028).

Все данные хранятся в PostgreSQL.

## Требования

- Node.js 18+
- Docker + Docker Compose
- npm или yarn

## Быстрый старт (локально)

1. Установите зависимости:

```bash
npm install
```

2. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.

3. Скопируйте настройки:

```bash
cp .env.example .env
```

4. Заполните `.env`:
- `BOT_TOKEN` — токен бота;
- `ADMIN_IDS` — Telegram ID администраторов (через запятую);
- `DATABASE_URL` — строка подключения к PostgreSQL в Docker-контейнере (например: `postgresql://jwbot:jwbot@localhost:5433/jw_talks`);
- `DEFAULT_CONGREGATION_NAME` — название первой общины при `/grant` без указания общины (опционально).

5. Поднимите PostgreSQL в Docker:

```bash
docker compose up -d postgres
```

6. Запустите бота в dev-режиме:

```bash
npm run dev
```

## Production (только Docker Compose)

1. Подготовьте `.env`:
```bash
cp .env.example .env
```
Заполните минимум `BOT_TOKEN` и `ADMIN_IDS`.

2. Запустите контейнеры:

```bash
docker compose up -d --build
```

3. Полезные команды:
- Логи бота: `docker compose logs -f bot`
- Остановка: `docker compose down`

Примечания:
- `DATABASE_URL` для контейнера бота задаётся в `docker-compose.yml`.
- PostgreSQL публикуется на `localhost:5433` (чтобы не конфликтовать с локальным `5432`).
- Данные БД хранятся в Docker-томе `postgres-data`.
- Таблицы в БД создаются автоматически при первом запуске.
- Production-запуск поддерживается только через Docker Compose.

Важно: ожидающие выдачи доступа через `/grant` (до `/start` пользователя) хранятся в памяти процесса бота. После перезапуска бота такие выдачи нужно повторить.

## Команды бота

| Команда | Описание |
|--------|----------|
| `/start` | Приветствие и справка; при выданном ранее `/grant` — привязка доступа к вашему аккаунту. |
| `/help` | Краткая справка по командам. |
| `/grant @username [община]` | Выдать пользователю доступ к боту (и при необходимости к указанной общине). Только для администратора. Если община не указана и в системе одна община — доступ к ней. |
| `/list` | Расписание публичных речей по датам (по вашим общинам; при нескольких — выбор кнопкой). |
| `/check` | Проверить историю по номеру речи: команда запускает запрос номера, после ввода бот показывает, была ли такая речь и когда именно. |
| `/add` | Пошаговое добавление речи: община → дата → песня → номер речи → название → докладчик → телефон. |
| `/edit` | Редактирование речи: выбор даты и речи по кнопкам, затем выбор поля (дата, песня, № речи, докладчик, телефон). Название речи подставляется из списка при смене номера. |
| `/delete` | Удаление речи: выбор даты из расписания → подтверждение. |
| `/stats [община]` | Сводка и ТОП по прошедшим речам, постраничный полный список в чате + кнопки выгрузки XLSX (полный список и матрица по годам 2020-2028). |
| `/plans [община]` | Список речей (номер + название) — шаблон для подстановки при добавлении речи. Список задаётся при инициализации БД. |
| `/meeting_schedule [set\|rename ...]` | Настройки собрания: просмотр, изменение дня/времени и переименование (кнопками или через аргументы). |
| `/cancel` | Отменить текущую пошаговую операцию (`/add`, `/edit`, `/meeting_schedule`). |

Интерфейс бота — на русском языке.

## Структура проекта

```
src/
  index.ts              # Точка входа, запуск бота и планировщика
  bot/
    commands/           # Команды: start, list, add, edit, delete, stats, plans, meetingSchedule
      start.ts, list.ts, add.ts, edit.ts, delete.ts, stats.ts
      plans.ts          # /plans — просмотр списка речей
      meetingSchedule.ts # /meeting_schedule — день/время/название собрания
    middlewares/        # auth (авторизация, /grant), logging
    utils/              # splitMessage — разбиение длинных сообщений
  scheduler/
    notifications.ts   # Уведомления за 7 дней и напоминание накануне
  db/                   # PostgreSQL: схема, типы, репозитории
    schema.ts, types.ts, repositories.ts, index.ts
```

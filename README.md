# JW Talks Planner — бот для ответственных за публичные речи

Telegram-бот на TypeScript (Telegraf.js + SQLite) для планирования публичных речей в собрании Свидетелей Иеговы.

## Возможности

- **Публичные речи**: добавление, редактирование, удаление и просмотр.
- **Поля речи**: дата, номер песни, номер речи, название речи, имя докладчика, номер телефона.
- **Список речей (планы)**: по каждой общине — номер и название речи; добавление списком (`1 Название. 2 Название!` …), редактирование и удаление. Используется при добавлении речи для подстановки названия по номеру.
- **Несколько общин**: у каждой общины свой ответственный; доступ выдаёт администратор.
- **Авторизация**: администратор выдаёт доступ командой `/grant @username` (при необходимости указывается название общины; если общины нет — она создаётся).
- **Переименование общины**: команда `/rename_congregation` для смены названия общины.
- **Уведомления**:
  - за 7 дней до речи — просьба подтвердить докладчика;
  - за 12 часов — напоминание (при отсутствии времени в БД — за 1 день до даты речи).
- **Статистика** (`/stats`): сколько раз каждая речь звучала, когда в последний раз, кто выступал чаще всего.

Все данные хранятся локально в SQLite.

## Требования

- Node.js 18+
- npm или yarn

## Установка

1. Клонируйте репозиторий или скопируйте файлы проекта.

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и получите токен.

4. Скопируйте пример настроек в `.env` (например: `copy .env.example .env` в Windows или `cp .env.example .env` в Linux/macOS).

   В файле `.env` укажите:

   - `BOT_TOKEN` — токен бота от BotFather.
   - `ADMIN_IDS` — ваш Telegram user ID (можно несколько через запятую). Узнать ID можно через [@userinfobot](https://t.me/userinfobot).
   - При необходимости `DB_PATH` — путь к файлу SQLite (по умолчанию `./data/talks.db`).
   - При необходимости `DEFAULT_CONGREGATION_NAME` — название общины при первом `/grant` без указания общины (по умолчанию «Община 1»).

## Запуск

- **Режим разработки** (с автоперезапуском при изменении кода):

  ```bash
  npm run dev
  ```

- **Сборка и запуск в production**:

  ```bash
  npm run build
  npm start
  ```

- **Запуск через Docker Compose**:

  1. Создайте `.env` из `.env.example` и укажите `BOT_TOKEN` и `ADMIN_IDS`.
  2. Соберите и запустите контейнер:

     ```bash
     docker compose up -d --build
     ```

  База SQLite хранится в Docker-томе `bot-data` и сохраняется между перезапусками. Логи: `docker compose logs -f bot`.

База данных создаётся автоматически при первом запуске (включая папку `data`, если её нет).

## Команды бота

| Команда | Описание |
|--------|----------|
| `/start` | Приветствие и справка; при выданном ранее `/grant` — привязка доступа к вашему аккаунту. |
| `/help` | Краткая справка по командам. |
| `/grant @username [община]` | Выдать пользователю доступ к боту (и при необходимости к указанной общине). Только для администратора. Если община не указана и в системе одна община — доступ к ней. |
| `/list` | Список предстоящих речей (по вашим общинам; при нескольких — выбор кнопкой). |
| `/add` | Пошаговое добавление речи: община → дата → песня → номер речи → название → докладчик → телефон. |
| `/edit` | Редактирование речи: выбор даты и речи по кнопкам, затем выбор поля (дата, песня, № речи, докладчик, телефон). Название речи подставляется из списка при смене номера. |
| `/delete <id>` | Удаление речи по ID (с подтверждением). |
| `/stats [община]` | Статистика по прошедшим речам и докладчикам. |
| `/plans [община]` | Список речей (номер + название) по общине — шаблон для подстановки при добавлении речи. |
| `/add_plan` | Добавить в список речей (пошагово или списком: `1 Название. 2 Название!` и т.д.). |
| `/edit_plan` | Редактировать запись в списке речей. |
| `/delete_plan` | Удалить запись из списка речей. |
| `/rename_congregation [старое новое]` | Переименовать общину (при одной общине — запрос нового названия; при нескольких — выбор кнопкой или аргументы). |

Интерфейс бота — на русском языке.

## Структура проекта

```
src/
  index.ts              # Точка входа, запуск бота и планировщика
  bot/
    commands/           # Команды: start, list, add, edit, delete, stats, plans, congregation
      start.ts, list.ts, add.ts, edit.ts, delete.ts, stats.ts
      plans.ts          # /plans, /add_plan, /edit_plan, /delete_plan
      congregation.ts   # /rename_congregation
    middlewares/        # auth (авторизация, /grant), logging
    utils/              # splitMessage — разбиение длинных сообщений
  scheduler/
    notifications.ts   # Уведомления за 7 дней и за 12 часов (накануне)
  db/                   # SQLite: схема, типы, репозитории
    schema.ts, types.ts, repositories.ts, index.ts
```
